# Симуляция метро на C++

Этот проект моделирует работу системы метро с использованием многопоточности на C++. Каждый поезд движется по заранее определённой линии, останавливается на станциях и возвращается в депо (если предусмотрено). Симуляция включает несколько линий с различными характеристиками, включая челночную.

## Особенности

- Симуляция движения поездов по линиям метро
- Каждый поезд работает в своём потоке
- Используются мьютексы для предотвращения одновременного доступа к станциям
- Поддержка движения в обоих направлениях и возвращение в депо
- Обработка челночных маршрутов

## Линии метро

- **Красная линия**
- **Зелёная линия**
- **Фиолетовая линия**
- **Жёлтая линия** (челночная)

## Требования

- C++11 или новее (для использования потоков, мьютексов и пр.)
- Компилятор с поддержкой C++11 (например, GCC, Clang, MSVC)

## Структура проекта

- `metro.h` — содержит определение класса `Metro` и вспомогательные структуры
- `metro.cpp` — реализация логики инициализации линий и движения поездов
- `main.cpp` — точка входа, запускающая симуляцию
- 
### Для **Linux** :
```bash
git clone https://github.com/afandieva/Subway.git
cd Metro
cmake -S . -B build
cd build
make
./Metro 
```
#### Статическая сборка:

1. Убедитесь, что в `CMakeLists.txt` указаны настройки статической линковки.
2. Выполните команды:

```bash
cmake -S . -B build
```

3.
```bash
cd build
make
```

После этого будет создан исполняемый файл в текущей папке.


#### Динамическая сборка:

Аналогично статической, но с включением `BUILD_SHARED_LIBS=ON` в `CMakeLists.txt`.
## Примечания

- Поезда работают в течение 1 минуты (реального времени).
- На каждой станции поезд останавливается на 300 миллисекунд.
- Вывод сообщений синхронизирован с помощью мьютексов, чтобы избежать наложения.
